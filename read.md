# BK Shop

Page de contact et de commande de **BK Shop**, réalisée avec React et Vite.
La page permet aux visiteurs de contacter la boutique par téléphone ou
WhatsApp, et de retrouver ses comptes Instagram et Facebook.

## Technologies

- React 18
- Vite
- CSS moderne avec mise en page responsive

## Installation

Installez les dépendances du projet avec :

```bash
npm install
```

## Lancement en développement

Pour démarrer le serveur de développement :

```bash
npm run dev
```

Vite indiquera ensuite l'adresse locale à ouvrir dans le navigateur.

## Génération de production

Pour créer la version optimisée du site :

```bash
npm run build
```

Les fichiers générés sont placés dans le dossier `dist/`.
